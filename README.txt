CS 315 Assignment 3 Starter Code

Files:
- index.html
- style.css
- app.ts

Your job:
1. Read and understand the starter code.
2. Complete the TODO sections in app.ts.
3. Compile app.ts with TypeScript:
       tsc.cmd app.ts
   (or tsc app.ts in Command Prompt/macOS/Linux)
4. The compiler will generate app.js.
5. Run index.html with Live Server for local testing.
6. For ICE deployment, upload index.html, style.css, and app.js to public_html/assignment3/.
7. Keep app.ts in your Brightspace source-code submission even though the browser runs app.js.

Note: JSONPlaceholder simulates POST requests. A newly created post is returned in the response but is not permanently stored on the server.
