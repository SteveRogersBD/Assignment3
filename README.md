# CS 315 Assignment 3

Mini Mission Board application using the JSONPlaceholder API.

## Run locally

1. Compile the TypeScript file:

   ```text
   tsc app.ts
   ```

2. Open `index.html` with Live Server or another local web server.

## Main files

- `index.html`: Page structure
- `style.css`: Page styling
- `app.ts`: TypeScript source
- `app.js`: Browser JavaScript generated from `app.ts`

The application loads users, displays posts for a selected user, validates new posts, and submits new posts through JSONPlaceholder.
